Como formatar o texto das regras
  • Deixe uma linha em branco entre os parágrafos.
  • ## Título cria um subtítulo dentro da seção.
  • - item cria uma lista.
  • **texto** deixa em negrito.
  • | Infração | Valor | Pontos | cria uma tabela (a primeira linha é o cabeçalho).
  • O botão Adicionar foto envia a imagem e coloca ela no fim do texto; mova a linha ![legenda](…) para onde quiser.
